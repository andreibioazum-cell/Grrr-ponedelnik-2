# Правка правил и баланса прямо в веб-консоли

`firebase deploy --only database` — это просто способ залить `firebase.rules.json`
из терминала. Терминал не обязателен: та же самая публикация делается мышкой в
веб-консоли Firebase, в визуальном редакторе. Ниже — оба нужных действия.

Проект: `cubicbattleserver-19ae2` → <https://console.firebase.google.com>.

## 1. Опубликовать правила (вместо `firebase deploy --only database`)

1. Слева **Build → Realtime Database**.
2. Сверху вкладка **Rules** (Правила) — это и есть визуальный редактор.
3. Открой в репозитории файл `firebase.rules.json`, скопируй его **целиком**
   (включая первую строку `{` и последнюю `}`) и вставь в редактор, заменив
   старый текст: `Ctrl+A`, затем `Ctrl+V`.
4. Нажми **Publish** (Опубликовать).
5. Firebase покажет зелёное подтверждение. Если он ругается на синтаксис —
   значит вставился не весь файл или браузер заменил символы: в правилах должны
   быть обычные `&&`, `>=`, `<=`, а не `&amp;&amp;`, `&gt;=`.

Файл целиком вставлять обязательно, если ты ещё не публиковал правила из этой
ветки: в них, кроме ограничения на кубки, есть ключ `emerald` для изумруда и
диапазон `event` 0..4 для кубика. Старые правила их не пропустят.

### Если хочется поменять только две строки

Если правила из этой ветки уже опубликованы раньше (изумруд покупается, кубик
включается), достаточно поправить два `validate`: `cups` и `candies`.
В редакторе нажми `Ctrl+F`, найди `newData.val() <= 10000000` — это две строки
(кубки и конфеты). Замени их на:

```
"cups": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 10000000 && (auth != null && (auth.token.email.toLowerCase() == 'dimasi4ek229@cb4.game' || auth.token.email.toLowerCase() == 'qwertyuiopaj1234@cb4.game') || !data.exists() || newData.val() <= data.val() + 1000)" },
"candies": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 10000000 && (auth != null && (auth.token.email.toLowerCase() == 'dimasi4ek229@cb4.game' || auth.token.email.toLowerCase() == 'qwertyuiopaj1234@cb4.game') || !data.exists() || newData.val() <= data.val() + 1000)" },
```

Сохрани кнопкой **Publish**. Смысл: за одну запись баланс может вырасти не
больше чем на 1000, администраторы — без ограничения.

> Правила — это только дополнительная защита. Само обнуление кубков чинит
> обновление APK: игра больше не отправляет нули после выхода из аккаунта.
> Поэтому если с правилами возиться сейчас не хочется, обнови APK, а правила
> опубликуй позже.

### Новые ключи этой версии правил

В `firebase.rules.json` из этой ветки появились ключи CodeCracker —
`codecracker_level` и `codecracker_levels` (у него своя ветка уровней, не
общая с обычным кубом), а диапазон `azum_skin` расширен с 0..1 до 0..3
(раньше игра не могла записать скин, и PATCH прогресса отклонялся целиком).

Пока эти правила не опубликованы, игра шлёт в базу профиль с ключами
CodeCracker, и Firebase отклоняет **весь** запрос: не поделать, профиль
не сохранится. Поэтому после обновления APK опубликуй правила целиком
(шаг 1 выше) — или точечно добавь в редакторе два `validate`:

```
"codecracker_level": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 3" },
"codecracker_levels": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 3" },
```

и поправь диапазон скина на `"azum_skin": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 3" }`.

## 2. Вернуть кубки (визуальный редактор данных)

Консоль пишет в базу **в обход правил**, поэтому руками можно поставить любое
число — это не «чит», а восстановление своего же баланса.

1. **Build → Realtime Database → вкладка Data** (Данные).
2. Разверни дерево: `users` → твой ник (например `dimasi4ek229`).
3. У поля `cups` наведи мышь на значение → появится карандаш (или двойной
   клик по числу) → впиши нужное число → `Enter`.
4. Обнови игру: при следующем входе профиль загрузится из базы уже с этим числом.

Если в игре после этого всё равно 0 — значит игра ещё со старым APK: он при
входе перезапишет базу своим локальным нулём. Сначала обнови APK из CI, затем
правь `cups`.

## 3. Как проверить, что всё в порядке

- В **Rules** поиск по `data.val() + 1000` находит две строки (кубки и
  конфеты) — значит новые правила опубликованы.
- В **Data** у `users/<ник>/cups` стоит твоё число, а не 0.
- Войди в игру, сыграй бой, выйди из аккаунта и войди снова: кубки должны
  остаться на месте.
