# Скриптинг на C и Студия персонажа (Roblox-стиль)

Geometrium — не просто воксель-песочница, а платформа: свой персонаж,
свои анимации, свои модели и **настоящие скрипты на чистом C** (не Lua,
не JS). Онлайн при этом прежний — Firebase Realtime Database.

## 1. Свой персонаж

В игре: **Профиль → Студия персонажа**.

- **4 модели** (`geo_models[]` в `src/game/geo/geo_studio.inc`): Классика,
  Стройный, Робот (антенна), Рыцарь (шлем). Модель — это таблица
  пропорций и аксессуаров, рендерер строит тело из боксов по ней.
- **4 слота материалов**: голова / тело / руки / ноги, по 8 материалов
  (`geo_skin_tex[]`: кожа, мрамор, сталь, обсидиан, янтарь, кобальт…).
- Выбор сохраняется в профиль (`geometrium_profile.dat`) и **синхронизируется
  по сети**: другие игроки видят именно твою модель, материалы и анимацию
  (поля `m`, `sk`, `a` в `/geometrium/rooms/<room>/players/<uid>.json`).

Новая модель персонажа = новая строка в `geo_models[]`. Новый материал =
новая текстура 32×32 в `assets/textures/` + строка в `geo_skin_tex[]`.

## 2. Анимации

Анимация — таблица кейфреймов `GeoAnimClip` (`geo_anim_clips[]`):
каждый ключ — время и угол на каждый сустав (ноги, руки, голова, тело,
подпрыгивание). Движок интерполирует между ключами, зацикленные клипы
крутятся по кругу. Встроены: `idle`, `walk`, `run`, `jump`, `fall`,
`swim`, `wave`, `dance`. Состояние выбирает конечный автомат:
эмоция → вода → воздух (прыжок/падение) → бег → ходьба → покой.

Новая анимация = новый элемент в enum `ANIM_*` + таблица ключей.
Эмоции (`wave`, `dance`) включаются в Студии персонажа и видны всем
игрокам комнаты.

## 3. Скрипты на C

Файл: **`src/game/geo/geo_user_scripts.inc`**. Скрипт — две функции на C
и одна строка в реестре:

```c
static void my_script_start(GeoScriptApi *api) {
    /* один раз при старте мира */
    api->spawn_part("MyPad", 50.0f, 21.0f, 48.0f, 2.0f, 0.5f, 2.0f, 16);
}
static void my_script_tick(GeoScriptApi *api, float dt) {
    /* каждый кадр */
    GeoPart *p = api->find_part("MyPad");
    if (p) p->yaw += dt;                       /* вращаем Part */
    if (api->player_on_part("MyPad"))
        api->player_bounce(13.0f);             /* батут! */
}
/* в реестре внизу файла: */
{"my_script", my_script_start, my_script_tick},
```

API (`GeoScriptApi` в `geo_studio.inc`): `get_block` / `set_block`,
`explode`, `spawn_part` / `find_part` (динамические 3D-объекты Part,
как Workspace в Roblox — рендерятся в мире с той же окклюзией, что и
блоки), `player_pos`, `player_bounce`, `player_on_part`, `time`, `print`.

В комплекте три рабочих примера: **BouncePad** (батут), **Spinner**
(вращающаяся платформа), **Builder** (строит башню из мрамора при
старте мира). Проверка без телефона: `tools/host_test/test_studio.c`
гоняет все скрипты на заглушке мира (`cc ... -lm && ./test_studio`,
также запускается в CI).

## 4. Онлайн

Тот же Firebase, что и раньше: комнаты, игроки (позиция + модель +
материалы + анимация), блоки мира, чат, аккаунты. HTML в репозитории —
только админ-панель Firebase (`index.html`), игра полностью на C.
